# Русский: словарь терминов

Тон: нейтральный технический, как в хорошей документации для разработчиков; без маркетинга, обращение на «вы».

Примечание о переводе (одна строка в начале каждого переведённого файла): _Это перевод английской документации; при расхождениях действует английская версия._

| English | Русский | Note |
| --- | --- | --- |
| task | задача | Без английского в скобках. Не «таска», не «тикет» (тикет — это запись в трекере). |
| plan | план | Без английского в скобках. |
| milestone | веха | Устоявшийся термин проекта. Не «milestone» и не «фаза». |
| stage | этап | Не «шаг», не «стейдж». |
| criterion | критерий | Бывает кодовым и поведенческим. |
| profile | профиль | Файл настройки проекта; ключи профиля не переводятся. |
| owner | владелец | Не «оператор», не «пользователь». |
| planner | планировщик | |
| executor | исполнитель | Не «разработчик». |
| reviewer | ревьюер | Так говорят в русскоязычном сообществе. |
| model tier | уровень модели | Значения `frontier`, `strong`, `efficient` остаются как есть. |
| role assignment | раскладка ролей | |

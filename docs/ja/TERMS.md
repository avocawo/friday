# 日本語版の用語集

トーン: 日本語の開発者向けドキュメントで一般的な、中立的な技術文書の文体（です・ます調）。宣伝的な表現は使わず、句読点は全角の「、」「。」を使う。

各翻訳ファイルに入れる翻訳に関する注記:

_この文書は英語版ドキュメントの翻訳です。内容が異なる場合は、英語版が優先されます。_

| English | 日本語 | Note |
| --- | --- | --- |
| task | タスク | 英語は併記しない。 |
| plan | 計画 | 「プラン」は使わない。 |
| milestone | マイルストーン | 英語は併記しない。 |
| stage | ステージ | 初出で「ステージ (stage)」とは書かず、そのまま用いる。工程の意味の「段階」は使わない。 |
| criterion | 基準 | 複数形は「基準」のまま。受け入れ基準を指す。 |
| profile | プロファイル | 英語は併記しない。 |
| owner | オーナー | 「所有者」「ユーザー」は使わない。 |
| planner | プランナー | モデルの役割名。英語は併記しない。 |
| executor | エグゼキューター | 実装を担当するモデルの役割名。英語は併記しない。 |
| reviewer | レビュアー | 英語は併記しない。 |
| model tier | モデルティア | 初出のみ「モデルティア (model tier)」と英語を併記する。 |
| role assignment | ロール割り当て | 初出のみ英語を併記する。 |
| gate | ゲート | 初出のみ「ゲート (gate)」と英語を併記する。コード中のキー名は英語のまま。 |
| milestone review | マイルストーンレビュー | 英語は併記しない。 |
| final review | 最終レビュー | 英語は併記しない。 |
| blind check | ブラインドチェック | 初出のみ英語を併記する。 |
| browser acceptance | ブラウザ受け入れ確認 | 初出のみ英語を併記する。 |
| disputed finding | 争点となった指摘 | 初出のみ英語を併記する。 |
| card | カード | 英語は併記しない。 |
| journal | ジャーナル | 英語は併記しない。 |
| worktree | ワークツリー | Git の用語。英語は併記しない。 |
| draft MR | ドラフト MR | 「ドラフト」は GitHub 日本語版に合わせる。MR は略語のまま。 |
| pipeline | パイプライン | 英語は併記しない。 |
| vendor | ベンダー | 英語は併記しない。 |
| test environment | テスト環境 | 英語は併記しない。 |
| preview | プレビュー | 英語は併記しない。 |
| finding | 指摘 | レビューでの指摘。「発見」は使わない。 |
| verdict | 判定 | 「評決」は使わない。 |
| sandbox | サンドボックス | 英語は併記しない。 |
| spending | コスト | 費用の累計を指す。「支出」は使わない。 |

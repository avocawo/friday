# Friday

_この文書は英語版ドキュメントの翻訳です。内容が異なる場合は、英語版が優先されます。_

個人用の開発パイプライン。複数のベンダーのモデルを使って、タスクを計画からドラフト MR まで進め、その成果物を検査します。

## 作業

**タスク**:
オーナーにとっての作業の単位。専用のカード、ブランチ、ワークツリーを持ち、通常はトラッカーのチケットに対応します。
_Avoid_: ジョブ、案件

**計画**:
タスクのマイルストーンとステージの一覧。受け入れ基準を含み、オーナーが承認します。
_Avoid_: プラン、予定

**マイルストーン**:
連続する 2〜5 個のステージのまとまり。ゲートとレビューを全体として通ります。
_Avoid_: フェーズ、工程

**ステージ**:
計画の最小の単位。1 回のコミットで終わります。
_Avoid_: ステップ、段階

**基準**:
ステージに対する検証可能な受け入れ条件。コード基準 (差分に対して確認) か、動作基準 (ブラウザで観察) のどちらかです。
_Avoid_: 要件、条件

**プロファイル**:
1 つのプロジェクトに対して Friday を設定する JSON ファイル (リポジトリ、モデル、ロール、ゲート、ブラウザ、トラッカー、ジャーナル、公開)。`extends` キーで別のプロファイルを拡張できます。
_Avoid_: 設定ファイル

## ロール

**オーナー**:
計画を承認し、ドラフト MR を受け入れ、争点となった指摘に決着をつける人。
_Avoid_: 所有者、ユーザー

**プランナー**:
計画を書くモデル。
_Avoid_: 設計者

**エグゼキューター**:
マイルストーンのコードを書くモデル。
_Avoid_: 開発者、実装者

**レビュアー**:
計画、マイルストーン、または最終的な差分をレビューし、基準に対する判定を下すモデル。
_Avoid_: 査読者、チェッカー

**モデルティア**:
モデルの能力のクラス。`frontier`、`strong`、`efficient` のいずれかです。
_Avoid_: モデルランク、モデルレベル

**ロール割り当て**:
タスクのロールに特定のモデルを割り当てること。計画が承認される前に確定されます。
_Avoid_: 役割分担

## チェック

**ゲート**:
モデルを使わない決定論的なチェック。特定のコミットに対して、隔離されたコンテナーで実行されます。
_Avoid_: CI、検証

**マイルストーンレビュー**:
別のベンダーのレビュアーが、ゲートのログとともにマイルストーンの差分をレビューすること。

**最終レビュー**:
MR の前に、タスク全体の差分をレビューすること。コードのブラインドチェックを含みます。
_Avoid_: 総合レビュー

**ブラウザ受け入れ確認**:
ローカルのテスト環境のブラウザで、マイルストーンの動作基準を観察すること。
_Avoid_: blind-behavior

**争点となった指摘**:
エグゼキューターが同意せず、ジャーナルを通じてオーナーに送られたレビュアーの指摘。
_Avoid_: 異議、却下された指摘

## 記録

**カード**:
タスクについての Friday のマシン上の状態。イベント、マイルストーン、判定、コストが含まれます。
_Avoid_: チケット

**ジャーナル**:
Obsidian にあるタスクの読みやすい履歴。カードからテンプレートで生成されます。
_Avoid_: ログ、日誌

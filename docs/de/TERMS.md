# Friday: Terminologie für die deutsche Dokumentation

Ton: sachlich-technisch, wie gute deutsche Entwickler-Dokumentation, per "du", ohne Werbesprache. Etablierte englische Fachbegriffe bleiben stehen und werden als deutsche Substantive großgeschrieben.

Übersetzungshinweis für jede Datei: _Dies ist eine Übersetzung der englischen Dokumentation; bei Abweichungen gilt die englische Fassung._

| English | Deutsch | Note |
| --- | --- | --- |
| task | Aufgabe | Beim ersten Vorkommen nicht in Klammern; im Code bleibt `task` unverändert. |
| plan | Plan | Wie im Englischen. |
| milestone | Meilenstein | Englisch nicht nötig. |
| stage | Etappe | Bewusst nicht "Phase"/"Schritt" (Avoid-Wörter); englisch "Stage" nur in Klammern bei Bedarf. |

# Friday

[English](../../GLOSSARY.md) · [Русский](../ru/GLOSSARY.md) · [简体中文](../zh-cn/GLOSSARY.md) · [日本語](../ja/GLOSSARY.md) · **한국어** · [Português (Brasil)](../pt-br/GLOSSARY.md) · [Español](../es/GLOSSARY.md) · [Deutsch](../de/GLOSSARY.md) · [Français](../fr/GLOSSARY.md) · [Bahasa Indonesia](../id/GLOSSARY.md)

_이 문서는 영어판 문서를 번역한 것입니다. 내용이 다를 경우 영어판이 우선합니다._

개인용 개발 파이프라인입니다. 여러 벤더의 모델을 활용해 작업을 계획부터 초안 MR까지 진행하고, 모델의 결과물을 검증합니다.

## 작업

**작업**:
오너에게 주어지는 하나의 업무 단위입니다. 자체 카드, 브랜치, 워크트리를 가지며 보통 트래커의 티켓 하나와 대응합니다.
_Avoid_: 잡, 미션, 태스크

**계획**:
작업의 마일스톤과 단계를 인수 기준과 함께 나열한 목록으로, 오너가 승인합니다.

**마일스톤**:
연속된 2~5개의 단계를 묶은 단위로, 게이트와 리뷰를 하나로 묶어 통과합니다.
_Avoid_: 페이즈, 이정표

**단계**:
계획을 이루는 가장 작은 단위로, 커밋 하나로 끝납니다.
_Avoid_: 스텝, 스테이지

**기준**:
단계가 충족해야 하는 검증 가능한 인수 조건입니다. 코드 기준(diff로 확인)과 동작 기준(브라우저에서 관찰) 중 하나입니다.

**프로필**:
프로젝트 하나에 대해 Friday를 설정하는 JSON 파일입니다(저장소, 모델, 역할, 게이트, 브라우저, 트래커, 저널, 전달). `extends` 키로 다른 프로필을 확장할 수 있습니다.

## 역할

**오너**:
계획을 승인하고, 초안 MR을 인수하고, 이견이 있는 지적을 해결하는 사람입니다.
_Avoid_: 소유자, 사용자, 운영자

**플래너**:
계획을 작성하는 모델입니다.

**실행자**:
마일스톤의 코드를 작성하는 모델입니다.
_Avoid_: 개발자, 익스큐터

**리뷰어**:
계획, 마일스톤, 최종 diff를 리뷰하고 기준에 대한 판정을 내리는 모델입니다.

**모델 등급**:
모델의 성능 분류로, `frontier`, `strong`, `efficient` 중 하나입니다.

**역할 배정**:
작업의 각 역할에 구체적인 모델을 지정하는 것으로, 계획이 승인되기 전에 확정됩니다.

## 검사

**게이트**:
모델을 쓰지 않는 결정적 검사로, 격리된 컨테이너에서 특정 커밋에 대해 실행됩니다.
_Avoid_: CI, 검증

**마일스톤 리뷰**:
다른 벤더의 리뷰어가 게이트 로그와 함께 마일스톤의 diff를 검토하는 것입니다.

**최종 리뷰**:
MR을 만들기 전에 작업 전체의 diff를 검토하는 것으로, 코드의 블라인드 검사를 포함합니다.

**브라우저 인수 확인**:
로컬 테스트 환경의 브라우저에서 마일스톤의 동작 기준을 관찰하는 것입니다.
_Avoid_: blind-behavior

**이견이 있는 지적**:
실행자가 동의하지 않아 저널을 통해 오너에게 전달된 리뷰어의 지적입니다.

## 기록

**카드**:
작업에 대한 Friday의 머신 상태로, 이벤트, 마일스톤, 판정, 비용을 담습니다.

**저널**:
카드에서 템플릿으로 만들어 Obsidian에 남기는, 사람이 읽을 수 있는 작업 이력입니다.

# Português (Brasil): glossário de termos

Tom: técnico e neutro, como em boa documentação para desenvolvedores brasileiros; sem marketing, tratamento por "você".

Nota de tradução (uma linha no início de cada arquivo traduzido): _Esta é uma tradução da documentação em inglês; em caso de divergência, vale a versão em inglês._

| English | Português (Brasil) | Note |
| --- | --- | --- |
| task | tarefa | Sem inglês entre parênteses. Não usar "job" nem "ticket" (ticket é o registro no tracker). |
| plan | plano | Sem inglês entre parênteses. |
| milestone | marco | Termo fixo do projeto. Não "milestone" nem "fase". |
| stage | etapa | Não "passo" nem "estágio". |
| criterion | critério | Pode ser de código ou de comportamento. |
| profile | perfil | Arquivo de configuração do projeto; as chaves do perfil não são traduzidas. |
| owner | dono | "Dono da tarefa"; não "operador" nem "usuário". Quem aprova o plano e aceita o draft MR. |
| planner | planejador | Modelo que escreve o plano. |
| executor | executor | Não "desenvolvedor". |
| reviewer | revisor | Modelo que faz a revisão. |
| model tier | nível do modelo | Primeira vez: "nível do modelo (model tier)". Os valores `frontier`, `strong`, `efficient` ficam em inglês. |
| role assignment | atribuição de papéis | Papéis: `plan`, `develop`, `review` etc. ficam em inglês quando são chaves. |
| gate | gate | Manter em inglês, como a comunidade costuma dizer; na primeira vez: "gate (verificação automática sem modelos)". Não "CI". |
| milestone review | revisão do marco | |
| final review | revisão final | |
| blind check | verificação cega | Revisão sem contexto, em pasta vazia. |
| browser acceptance | aceitação no navegador | |
| disputed finding | achado contestado | Não "problema discutido". |
| card | card | Manter em inglês (estado de máquina da tarefa); na primeira vez: "card (estado da tarefa)". |
| journal | diário | Diário da tarefa (Obsidian, jsonl). |
| worktree | worktree | Sempre em inglês. |
| draft MR | MR em rascunho | "MR" fica; na primeira vez: "MR (merge request) em rascunho". No glossário, "draft MR" pode ficar em inglês quando for nome próprio do fluxo. |
| pipeline | pipeline | Em inglês. |
| vendor | fornecedor | Fornecedor do modelo (Anthropic, OpenAI, Z.ai). Não "vendedor". |
| test environment | ambiente de teste | |
| preview | preview | Em inglês; ambiente isolado de visualização. |
| finding | achado | Observação da revisão. |
| verdict | veredito | |
| sandbox | sandbox | Em inglês. |
| spending | gasto | Gasto com modelos; não "custo" quando se trata do acumulado por tarefa. |

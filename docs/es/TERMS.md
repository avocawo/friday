# Español: glosario de términos

Tono: técnico y neutro, como en la buena documentación para desarrolladores; sin tono comercial, tuteo ("tú"), español internacional sin regionalismos.

Nota de traducción (una línea al principio de cada archivo traducido): _Esta es una traducción de la documentación en inglés; si hay diferencias, prevalece la versión en inglés._

| English | Español | Note |
| --- | --- | --- |
| task | tarea | Sin inglés entre paréntesis. No "ticket" (el ticket es el registro en el tracker). |
| plan | plan | Sin inglés entre paréntesis. |
| milestone | hito | Término fijo del proyecto. No "milestone" ni "fase". |
| stage | etapa | No "paso". |
| criterion | criterio | Puede ser de código o de comportamiento. |
| profile | perfil | Archivo de configuración del proyecto; las claves del perfil no se traducen. |
| owner | propietario | No "operador" ni "usuario". |
| planner | planificador | |
| executor | ejecutor | No "desarrollador". |
| reviewer | revisor | |
| model tier | nivel del modelo | Los valores `frontier`, `strong`, `efficient` se quedan tal cual. |
| role assignment | asignación de roles | |
| gate | gate | Se deja en inglés: así lo dicen los desarrolladores hispanohablantes. En la primera aparición se explica: "gate (comprobaciones deterministas sin modelos)". No "CI" ni "validación". |
| milestone review | revisión del hito | Sin inglés entre paréntesis. |
| final review | revisión final | Sin inglés entre paréntesis. |
| blind check | comprobación a ciegas | En la primera aparición: "comprobación a ciegas (blind check)". |
| browser acceptance | aceptación en el navegador | En la primera aparición: "aceptación en el navegador (browser acceptance)". |
| disputed finding | hallazgo en disputa | No "hallazgo discutido". |
| card | ficha | La ficha de estado de la tarea; no "tarjeta". |
| journal | diario | El historial legible de la tarea; no "bitácora" ni "log". |
| worktree | worktree | Se deja en inglés (término de Git). |
| draft MR | MR en borrador | "MR" se queda; "draft" se traduce como "en borrador". |
| pipeline | pipeline | Se deja en inglés; es la palabra habitual entre desarrolladores. |
| vendor | proveedor | Se refiere a la empresa que ofrece el modelo (Anthropic, OpenAI, Z.ai). |
| test environment | entorno de pruebas | |
| preview | preview | Se deja en inglés cuando es el nombre de la clave `preview` o un entorno aislado; en prosa, "preview" sin traducir. |
| finding | hallazgo | Observación de un revisor. |
| verdict | veredicto | |
| sandbox | sandbox | Se deja en inglés (término habitual); en la primera aparición puede aclararse "entorno aislado". |
| spending | gasto | Lo gastado en tokens/dinero por tarea. |

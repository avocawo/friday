# Исполнитель сам запускает проверки, а официальный гейт остаётся доказательством

Раньше у разработчика не было shell: об ошибках типов и линтера он узнавал только от гейта, а тот отдавал хвост лога без самих ошибок. Каждая опечатка стоила полного круга через Friday. Теперь исполнитель получает минимальный набор инструментов без запросов разрешений: чтение и правку файлов worktree и запуск команд проверки из профиля (для фронтенд-проекта пилота — ESLint, vue-tsc, vitest по затронутым файлам). Сеть, `git push` и запись вне worktree закрыты.

Гейт — детерминированные проверки без моделей в изолированном Docker на конкретном коммите (для фронтенд-проекта пилота — `npm run validate:diff`). Он идёт в конце вехи и в финале, его лог получает ревьюер. Отчёту исполнителя «у меня зелёное» Friday не верит: засчитывается только гейт. При провале исполнитель получает блоки упавших проверок, а не хвост лога.

## Considered Options

- **Оставить исполнителя без shell ради изоляции.** Отклонено: это главный источник повторов в пилоте, а изоляция worktree и закрытая сеть дают нужную защиту.

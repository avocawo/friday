# Несколько задач одновременно: места и квоты вместо глобальных блокировок

Владелец ведёт несколько задач в одном репозитории через worktree, и Friday должен работать так же. Глобальные блокировки `gate:global` и `resource:browser:global` сериализовали даже чтение неизменного коммита. Их заменяют счётчики мест с ёмкостью из настроек машины:
- гейты — по умолчанию 1–2 одновременно: в пилоте два тяжёлых гейта исчерпали ресурсы;
- браузерные проверки — у каждой задачи своя вкладка в общем Chrome и свой порт preview.

Короткая блокировка репозитория остаётся только на `git fetch` и `worktree add`.

Квоты вендоров учитываются на всю машину: у Z.ai квота общая для всех инструментов, с окнами 5 часов и 7 дней. Когда квота исчерпана, задача ставит замену по ADR 0002 или ждёт, и статус пишет, чего именно она ждёт и до какого времени. При утверждении плана Friday сверяет его файлы с файлами других активных задач и предупреждает о будущих конфликтах.

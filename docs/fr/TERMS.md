# Français : glossaire des termes

Ton : technique et neutre, comme dans une bonne documentation pour développeurs ; pas de ton marketing ; vouvoiement.

Note de traduction (une ligne au début de chaque fichier traduit) : _Ceci est une traduction de la documentation anglaise ; en cas de divergence, la version anglaise fait foi._

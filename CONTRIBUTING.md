# Разработка Friday

Friday — самостоятельный инструмент. Поведение для конкретного проекта должно задаваться его настройками, а не зашиваться в общее ядро.

- Поддерживайте Python 3.9. Добавляйте зависимости только при обоснованной необходимости.
- Изменяя контракт команды, обновляйте справку, README и тесты на реальный вызов процесса, включая код выхода и потоки вывода.
- Тесты должны работать с временными данными и не менять пользовательские проекты.
- Не публикуйте данные и не выполняйте внешние действия без соответствующего разрешения владельца.
- Для каждого этапа запускайте `python3 -m unittest discover -s tests -v`; проверяйте новые команды из README.

Публичных возможностей, кроме перечисленных в README, пока нет. Новые возможности описывайте вместе с их реализацией.
